## 👋 About This Portfolio

Welcome to my Cybersecurity Learning Portfolio!

I am a Software Engineering undergraduate at the University of Kelaniya, building my knowledge of cybersecurity through structured learning, practical exercises, and hands-on investigations.

This repository documents my progress as I explore cybersecurity fundamentals, network security, Linux system administration, packet analysis, and security assessment techniques.

Rather than focusing only on theory, I aim to understand how security concepts apply to real systems, practise them in controlled environments, analyse the results, and document my findings clearly.

**This repository is an ongoing learning project.** Weeks 1–4 represent my initial learning phase, and I will continue adding new weeks, practical labs, tools, investigations, and security projects as I develop my skills.

---

## 🎯 Learning Objectives

- Understand fundamental cybersecurity concepts and security principles.
- Identify assets, threats, vulnerabilities, and risks.
- Develop a practical understanding of networking protocols and communication.
- Use Wireshark to capture and analyse network traffic.
- Practise Linux commands, system observation, and file permissions.
- Perform basic network discovery in authorised lab environments.
- Interpret technical evidence carefully and document findings professionally.
- Build a public portfolio demonstrating continuous cybersecurity learning.

## 🔍 Key Learning Outcomes So Far

Through the initial four weeks, I have practised:

- Explaining confidentiality, integrity, and availability.
- Distinguishing assets, threats, vulnerabilities, and risks.
- Understanding authentication and authorisation.
- Observing ICMP, DNS, TCP, and TLS traffic using Wireshark.
- Understanding the TCP three-way handshake.
- Inspecting Linux users, network configuration, processes, and listening sockets.
- Comparing Linux file permissions such as `600` and `644`.
- Performing a basic Nmap scan against my own Ubuntu virtual machine.
- Comparing network scan results with local listening-port information.
- Documenting packet evidence and distinguishing observations from assumptions.

These outcomes reflect my learning and practice so far; I will continue developing them through further exercises.
