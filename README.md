## 👋 About This Portfolio

Welcome to my Cybersecurity Learning Portfolio!

I am a Software Engineering undergraduate at the University of Kelaniya, developing my cybersecurity knowledge through structured learning, practical exercises, and hands-on investigations.

This repository documents my progress as I explore cybersecurity fundamentals, network security, Linux system administration, packet analysis, web application security, vulnerability mechanisms, and security assessment techniques.

Rather than focusing only on theory, I aim to understand how security concepts apply to real systems, practise them in controlled and authorised environments, analyse the results, and document my findings clearly.

**This repository is an ongoing learning project.** It currently documents my learning activities across Weeks 1–8. I will continue adding new weekly exercises, practical labs, tools, investigations, and security projects as I develop my skills.

All practical security testing is conducted within my own lab environments or explicitly authorised training platforms.

## 🎯 Learning Objectives

- Understand fundamental cybersecurity concepts and security principles.
- Identify assets, threats, vulnerabilities, and risks.
- Develop a practical understanding of networking protocols and communication.
- Use Wireshark to capture and analyse network traffic.
- Practise Linux commands, system observation, and file permissions.
- Perform basic network discovery in authorised lab environments.
- Understand HTTP communication and web application architecture.
- Investigate common web application vulnerability mechanisms.
- Use Burp Suite to observe, inspect, and compare HTTP requests and responses.
- Evaluate security observations and recommend appropriate mitigations.
- Interpret technical evidence carefully and document findings professionally.
- Build a public portfolio demonstrating continuous cybersecurity learning.

## 🔍 Key Learning Outcomes

Through the first eight weeks, I have been developing practical knowledge in the following areas:

### Security Foundations & Networking

- Explaining confidentiality, integrity, and availability.
- Distinguishing assets, threats, vulnerabilities, and risks.
- Understanding authentication and authorisation.
- Observing ICMP, DNS, TCP, and TLS traffic using Wireshark.
- Understanding the TCP three-way handshake.

### Linux & Network Analysis

- Inspecting Linux users, network configuration, processes, and listening sockets.
- Comparing Linux file permissions such as `600` and `644`.
- Performing basic Nmap scans against my own Ubuntu virtual machine.
- Comparing network scan results with local listening-port information.
- Documenting packet evidence and distinguishing observations from assumptions.

### Web Application Security

- Understanding HTTP requests, responses, status codes, and headers.
- Exploring web application architecture and browser-to-server communication.
- Investigating common vulnerability mechanisms such as SQL injection, XSS, and broken access control.
- Understanding how an intercepting proxy works.
- Using Burp Suite to inspect and compare HTTP requests and responses.
- Performing controlled investigations in authorised training environments.
- Connecting security observations with potential impact and remediation recommendations.

These outcomes reflect my learning and practice so far. I will continue improving my technical understanding through further exercises and investigations.
